# Roles y permisos

| Acción | Inspector | Responsable | Administrador |
|---|---|---|---|
| Ver asignadas | Sí | Sí | Sí |
| Ver inventario completo | No, salvo permiso | Sí | Sí |
| Crear/editar estructura | No | Sí, auditado | Sí |
| Inspeccionar asignada | Sí | Si tiene permiso | Según permiso |
| Corregir inspección propia | Sí, auditado | Sí | Sí |
| Validar inspección | No | Sí | Según delegación |
| Registrar excepción | No | Sí | Sí |
| Crear/gestionar intervención | No | Sí | Sí |
| Gestionar usuarios | No | Limitado | Sí |
| Consultar auditoría | Propia/limitada | Sí | Sí |

Mínimo privilegio. Cuentas individuales. Desactivar usuarios no borra historial. Inspector no accede a estructuras no asignadas salvo autorización registrada. Administración debe poder transferirse a la municipalidad.
