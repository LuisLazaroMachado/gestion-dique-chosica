# Plan de pruebas

## Unitarias
Validar escalas, fórmula, Nmax=0, falta de indicadores, redondeo, estados y transiciones.

## Integración
Alta de estructura; asignación; inspección; fotos; validación; exposición; recálculo; intervención; ruta; auditoría.

## Offline
Descargar asignación, desconectar, crear inspección/fotos, reiniciar app, reconectar, sincronizar, reenviar y comprobar ausencia de duplicados y pérdida.

## Seguridad
Inspector consulta estructura no asignada; usuario desactivado inicia sesión; usuario sin permiso valida; acceso a foto; manipulación de puntaje desde cliente.

## Geoespacial
CRS, geometrías inválidas, índices, duplicados, ubicación provisional visible, rutas y restricciones.

## Campo
Piloto por tipología, comparación papel/móvil, comprensión de escalas, tiempos, fotos, sincronización y revisión profesional.

Cada caso registra ID, precondiciones, pasos, esperado, obtenido, estado, responsable, fecha y evidencia.
